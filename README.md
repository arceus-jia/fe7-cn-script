# 火焰纹章 烈火之剑 · 汉化版文本查询

《火焰纹章 烈火之剑》（GBA，2003）**火花 × 狼组汉化版**的全部游戏文本，整理成可以在线翻阅、检索的静态网页。

在线阅读：https://arceus-jia.github.io/fe7-cn-script/

网站提供两个版本，页面右下角可随时切换：

- **火花原版**：火花 × 狼组汉化版原文。
- **堇天修正 v0.9**：在原版基础上，采用堇天的纠错替换错译（[《狼组•火花汉化版错译盘点》](https://www.bilibili.com/read/readlist/rl724370)），人名统一使用堇天的译名。

## 关于译文

本站文本全部出自**火花 × 狼组汉化版**，人名、地名、道具名等译名均以该版本为准（如艾利乌德、赫克托耳、琳、奈哥尔），可能与其他汉化版本或官方译名不同。

译文的著作权归原作者（任天堂 / Intelligent Systems）及汉化组所有，网页中的角色头像、场景背景和剧情插画同样取自游戏，版权归任天堂 / Intelligent Systems 所有。本仓库仅用于查阅和参考，不提供 ROM。如有侵权，请联系删除。

  - 战斗对话、阵亡台词、村庄对话等

## 阅读说明

- **说话人**：根据游戏里的头像推断，绝大部分台词都已标出。教学提示、旁白、屏幕外的齐声应答等没有头像的台词不标说话人。
- **章号**：「艾15章・赫16章」表示该章在艾利乌德篇是第 15 章，在赫克托耳篇是第 16 章。赫克托耳篇多出「飞降的钩爪」「狂战士迪鲁汉」两章，所以后半段两篇的章号相差 1～2。章节名取自游戏原文。
- **两篇不同的段落**：艾利乌德篇和赫克托耳篇台词不同的地方，分别标注【艾利乌德篇】【赫克托耳篇】。
- **军师版本**：男军师版和女军师版只差「君」「小姐」这类称呼，正文只收男军师版。
- **占位符**：`{军师名}`、`{金额}`、`{道具}` 是游戏运行时替换的内容。
- **编号**：每段开头的 `#0A40` 这类编号是游戏内部的文本编号，可以用来精确定位和引用。

## 文本是怎么来的

文本直接从汉化版 ROM 中提取：

1. 解压游戏的 Huffman 压缩文本。
2. 根据汉化字库按 GBK 顺序排列的规律，结合 OCR 识别，还原出 2600 多个汉字的码表（`fe7_cn.tbl`），拿不准的字逐个人工核对过。
3. 解析事件脚本、战斗对话表、阵亡台词表和支援表，确定每段文本属于哪一章、由谁说出。

只出现过一两次的生僻字仍有极小可能认错。发现错字或分章错误，欢迎提 Issue，附上那段文本的 `#编号`。

## 自己生成

需要 Python 3，不依赖任何第三方库（图片也由脚本直接从 ROM 解码生成）。

1. 自备汉化版 ROM，放到 `rom/` 目录下（ROM 不会被提交到仓库）。
2. 在仓库根目录运行：

```bash
python3 build.py
```

生成结果：

- `docs/`：网页版，也就是 GitHub Pages 发布的内容（每次生成会整个重写）。根目录是火花原版，`docs/jt/` 是堇天修正版，两版目录结构相同：
  - `index.html`：首页和章节目录
  - `story/`：各章剧情、结局与后日谈
  - `support/`：支援目录和每个角色的支援对话
  - `data/`：角色资料、职业资料、武器与道具、名词表
  - `search.html`：全文搜索；`search-data.js` 是搜索用的全部文本
  - `other/`：阵亡与撤退台词、系统与说明文本、游戏音乐
  - `music/`：游戏音乐的音频（从仓库根目录的 `music/` 复制过来，两版共用）
  - `404.html` 会把旧版网址（如 `c05.html`）自动跳转到新位置
- `output/`：纯文本版，包括按章节、按角色拆分的 txt、全文本和名词表 CSV（不入库）

代码文件：

| 文件 | 作用 |
|---|---|
| `build.py` | 一键生成，串起下面几个模块，最后跑一遍自检 |
| `fe7text.py` | 文本解码、说话人推断、分章、结局表、角色 / 职业 / 武器道具数据 |
| `fe7gfx.py` | 头像、背景、剧情插画的解码 |
| `fe7site.py` / `fe7site.css` | 网页生成和样式 |
| `jintian.py` | 把堇天的专栏纠错匹配到游戏文本，生成 `jintian.json` |
| `music.json` | 游戏音乐的曲目表：英文曲名、使用场合（译自 Serenes Forest）、音频文件名 |
| `music/` | 游戏音乐的音频：Serenes Forest 的 MP3 用 `afconvert in.mp3 -o out.m4a -f m4af -d aac -b 64000 -s 1 -q 127` 转成，共约 81MB |

堇天修正的数据在 `jintian.json`，由 `jintian.py` 从专栏正文生成，记录了每条纠错的原文、修正文和它在游戏文本里的位置。译名表、笔误更正和版本号在 `fe7text.py` 里的 `JINTIAN_*` 常量中。

### 部署到 GitHub Pages

在仓库的 Settings → Pages 中，Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/docs`。
